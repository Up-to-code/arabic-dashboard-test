## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/arabic-dashboard-test.git
cd arabic-dashboard-test
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
